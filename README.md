# Lua Fundamentals for Project Zomboid Modding

Este repositorio documenta mi proceso de aprendizaje de **Lua**, enfocado específicamente en construir una base sólida para la **creación de mods en Project Zomboid**.

## 🎯 Propósito del repositorio

El objetivo principal es:

- Aprender y reforzar los **fundamentos de Lua**
- Comprender cómo se estructura y ejecuta Lua en el contexto de **Project Zomboid**
- Practicar conceptos clave antes de aplicarlos directamente al desarrollo de mods
- Tener un historial claro y versionado del progreso de aprendizaje

Este repositorio **no es un mod funcional**, sino una base de preparación técnica.

---

## 📚 Contenido

Aquí se incluyen:

- Ejercicios básicos de Lua
- Ejemplos prácticos derivados de tutoriales y documentación
- Pruebas de sintaxis, control de flujo, tablas, funciones y módulos
- Notas y experimentos relevantes para el ecosistema de Project Zomboid

La estructura puede evolucionar conforme avance el aprendizaje.

---

## 🧠 Enfoque y criterio

Una parte importante de este proceso es **resistir la presión de crear resultados inmediatos sin comprender los fundamentos**.

Aunque exista la tentación (o insistencia externa) de “hacer algo rápido” o “armarlos de chingadazo”, este repositorio prioriza:

- Entender primero cómo funciona el lenguaje
- Reducir deuda técnica desde el inicio
- Evitar soluciones improvisadas difíciles de mantener
- Construir conocimiento transferible a proyectos más complejos
- Fuck u Tico

El objetivo no es avanzar rápido, sino avanzar **bien**.
